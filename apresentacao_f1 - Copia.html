Apresentação técnica — banco de dados + aplicativo Python/PyQt6

1. Banco de dados — estrutura das tabelas +
Tabelas do banco
O banco tem 11 tabelas organizadas em camadas: cadastros base, temporada, resultados e relatórios consolidados.
pilotos, construtores, circuitos, curvas grandes_premios, carros piloto_carro_temporada resultados_corrida, tempos_volta, tempos_curva campeonato_pilotos, campeonato_construtores consolidado_piloto_gp, log_auditoria
Relacionamentos (FOREIGN KEY)
As tabelas se conversam através de chaves estrangeiras — garantindo que não existe resultado sem piloto, GP ou carro cadastrado.
resultados_corrida → pilotos (id_piloto) → grandes_premios (id_gp) → carros (id_carro) grandes_premios → circuitos (id_circuito) carros → construtores (id_construtor)
TINYINT UNSIGNED
Inteiro pequeno e positivo
Usado em número de curvas, voltas e número do piloto. O UNSIGNED remove os valores negativos, deixando 0 a 255.
numero_curva TINYINT UNSIGNED NOT NULL voltas_completas TINYINT UNSIGNED
DECIMAL(5,2)
Pontos sem erro de arredondamento
Pontuação armazenada com precisão exata. DECIMAL é melhor que FLOAT para dinheiro/pontos porque não acumula erro.
pontos_brutos DECIMAL(5,2) DEFAULT '0.00' -- ex: 25.00, 18.00, 15.00...
ENUM
Lista fechada de opções
Restringe o campo a valores específicos. O banco rejeita qualquer coisa fora da lista — garante integridade dos dados.
status ENUM('agendado','realizado','cancelado') status_piloto ENUM('finalizado','DNF','DNS','DSQ') tipo ENUM('lenta','media','rapida')
TIME(3)
Tempo com milissegundos
Guarda horas:minutos:segundos.milissegundos — essencial para tempos de volta e corrida na F1.
tempo_total TIME(3) -- ex: '01:31:44.742' recorde_volta TIME(3) -- ex: '01:27:38.241'
2. Aba Classificação — como funciona +
O que a aba faz
Mostra a tabela de classificação dos pilotos da temporada 2024 com posição, equipe, corridas disputadas, vitórias, pódios, voltas rápidas e pontos totais.
Botão "Atualizar Classificação" → atualizar_classificacao()
SQLPython
Executa uma query com JOIN em 5 tabelas. Usa COUNT, SUM e CASE WHEN para calcular todas as estatísticas ao vivo diretamente do banco — sem precisar salvar nada em memória.
SELECT CONCAT(p.nome, ' ', p.sobrenome) AS piloto, c.nome AS equipe, COUNT(rc.id_resultado) AS corridas, SUM(CASE WHEN rc.posicao_final = 1 THEN 1 ELSE 0 END) AS vitorias, SUM(CASE WHEN rc.posicao_final <= 3 THEN 1 ELSE 0 END) AS podios, SUM(CASE WHEN rc.volta_mais_rapida = TRUE THEN 1 ELSE 0 END) AS vr, ROUND(SUM(COALESCE(rc.pontos_brutos, 0)), 2) AS pts FROM pilotos p JOIN piloto_carro_temporada pct ON pct.id_piloto = p.id_piloto JOIN carros ca ON ca.id_carro = pct.id_carro JOIN construtores c ON c.id_construtor = ca.id_construtor LEFT JOIN resultados_corrida rc ON rc.id_piloto = p.id_piloto GROUP BY p.id_piloto ORDER BY pts DESC, vitorias DESC
No Python, o resultado popula a QTableWidget linha a linha com setItem():
self.table_classificacao.setRowCount(len(resultados)) for row_idx, row in enumerate(resultados): for col_idx, value in enumerate(row.values()): item = QTableWidgetItem(str(value)) item.setTextAlignment(Qt.AlignmentFlag.AlignCenter) self.table_classificacao.setItem(row_idx, col_idx, item)
Botão "Inicializar Dados" → inicializar_dados_temporada()
SQLPython
Chama a stored procedure sp_consolidar_gp para cada um dos 5 GPs. A procedure processa os resultados brutos e popula as tabelas de campeonato.
for gp_id in [1, 2, 3, 4, 5]: self.db.execute(f"CALL sp_consolidar_gp({gp_id})")
3. Aba Registrar Resultado — como funciona +
O que a aba faz
Permite registrar um novo resultado de corrida através de um formulário em uma janela separada (QDialog). Após o registro, a classificação é atualizada automaticamente.
Botão "Abrir Formulário" → abrir_dialog_resultado()
PythonUI
Abre o ResultadoDialog como janela modal. Se o usuário confirmar (DialogCode.Accepted), o app salva e recarrega a classificação automaticamente.
dialog = ResultadoDialog(self.db) if dialog.exec() == QDialog.DialogCode.Accepted: QMessageBox.information(self, "Sucesso", "Resultado registrado!") self.atualizar_classificacao() # atualiza automaticamente
O banco protege contra duplicatas com UNIQUE KEY — impossível registrar o mesmo piloto duas vezes no mesmo GP:
-- Na tabela resultados_corrida: UNIQUE KEY uq_resultado_piloto_gp (id_gp, id_piloto)

6. Infraestrutura — o que sustenta o app +
Conexão com o banco — classe Database
Python
O app usa uma classe Database separada para conectar ao MySQL. Se a conexão falhar na inicialização, o app encerra com mensagem de erro antes de qualquer coisa.
self.db = Database() if not self.db.connect(): QMessageBox.critical(self, "Erro", "Não foi possível conectar ao banco de dados!") sys.exit(1)
Interface — PyQt6 com abas
UI
A janela é um QMainWindow com um QTabWidget organizando as 4 funcionalidades. O tema escuro vermelho/preto é aplicado via setStyleSheet().
self.tabs = QTabWidget() self.tabs.addTab(create_classificacao_tab(), "Classificação") self.tabs.addTab(create_registrar_tab(), "Registrar") self.tabs.addTab(create_relatorios_tab(), "Relatórios") self.tabs.addTab(create_graficos_tab(), "Gráficos")
log_auditoria — tabela de auditoria automática
SQL
O banco registra automaticamente cada operação de INSERT, UPDATE ou DELETE com timestamp e o usuário MySQL que executou. O campo usuario usa DEFAULT (user()) — função nativa do MySQL que captura o usuário logado sem precisar passar nada.
CREATE TABLE log_auditoria ( operacao ENUM('INSERT','UPDATE','DELETE'), tabela VARCHAR(60), id_registro INT, descricao TEXT, usuario VARCHAR(100) DEFAULT (user()), -- captura automática ts TIMESTAMP DEFAULT CURRENT_TIMESTAMP -- data/hora automática )
